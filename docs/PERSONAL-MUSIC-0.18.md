# Personal music in 0.18

One ephemeral MusicInterests view combines the existing encrypted sources. Imported YouTube metadata stays in youtube_taste and is not silently copied into favourites, playlists, cloud sync or listening history. History-derived seeds and learned scores respect the listening-learning switch. Explicit hidden/never/break exclusions win; recent songs can seed related discovery without being recommended again during the anti-repeat window. Imported likes and optional owned-playlist songs affect artist affinity, but exact search order and saved playlist order remain intact.

Home has a top Made for you shelf, on-demand refresh and Start your radio. Discovery uses at most two distinct interest artists and one explicit-interest search, then applies feedback, duplicate removal, artist caps and recent-song filtering. Results live in Activity memory, with cancellation and source-signature/generation checks after disconnect or account import changes. Search surfaces imported matching tracks and up to four interest artists. Catalogue mixes and Smart discovery rank their eligible candidate pools using the same profile. Radio keeps its station/current-song anchors, adds at most one distinct interest-seed related request and applies the profile and existing hard exclusions at queue application time.

Owned-playlist import is opt-in before any playlist request. The existing youtube.readonly scope authorizes the read. GET playlists.list(mine=true,maxResults=3), playlistItems.list(maxResults=50) and videos.list metadata calls use the same fixed HTTPS Google origin, header-only bearer token, no redirects, bounded response sizes and timeouts. IDs are validated and de-duplicated; no raw API errors enter the UI. At most 100 liked and 100 playlist music tracks survive for 28 days. Disable the toggle and refresh to remove playlist imports; disconnect removes the entire optional collection. If playlists fail, liked music can still connect with an explicit partial-import message.

Music matching accepts category 10 or strong music metadata (Topic/VEVO channel, official audio/music-video/lyric-video title), with the existing duration, non-live, ID, artwork and non-talk checks. It is deliberately bounded and cannot establish that a user's whole account contains no music.

Google project verification remains external. Saving scope justification or publishing an audience does not remove Google's unverified-app warning. The privacy policy, OAuth justification and demonstration need to cover the owned-playlist option and app-wide recommendations. Never claim access to YouTube's private Home feed or watch history. Real Google authorization, imports for different channels/accounts, and phone listening still require device verification; fixture tests cannot prove them.
