# VEXO Music 0.12.0

Developer: Kavindu Kavishka.

- Solid charcoal surfaces, a forest-green greeting card and VEXO lime accents improve clarity.
- Smart Experience sits in the bottom navigation after Settings.
- Cloud MindRadio interprets music requests and refinements, with explicit consent and local fallback. Five requests per device/day; shared service quotas also apply.
- FairPlay rooms connect up to eight listeners for two hours, with fair requests, host controls and reconnect support. Each device streams independently; synchronization is best-effort.
- Private memories, listening-history search, playlist recovery, anti-repeat controls, discovery tools and Home customization are included.

Install as an update while keeping the existing app installed. App identity and existing private data are preserved. The APK uses the original signing certificate and a non-debuggable release build. Downloads/installation still require a user tap.

No paid plan was enabled. Licensed lyric search, full popularity/audio-feature data and authorized online downloads remain external dependencies. Physical-device background, battery and timing testing remains limited; report issues through Settings → Report a problem.
