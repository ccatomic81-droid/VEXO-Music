# VEXO Music 0.17.1

- Floating glass navigation pill with content scrolling behind it and safe spacing for the last row.
- Current-song mini-player appears above navigation only for active or paused playback; restored idle queues do not show a stale song.
- Clear YouTube errors for disabled API, request limits, missing permissions and accounts needing YouTube setup.
- YouTube permission screen explains Google verification and remains optional.

Google OAuth verification and enabling YouTube Data API v3 require owner console setup. This update does not claim to remove Google’s verification warning or complete that external setup.
