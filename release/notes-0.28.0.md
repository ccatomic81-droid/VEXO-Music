# VEXO Music 0.28.0

- Cleaner Home layout with a compact artist-search prompt and more room for music.
- Settings grouped into profile, playback, library and support, with proper navigation arrows.
- Simpler empty Library screens with one import/create action and a separate file-picker option.
- Up next counts only songs after the current track, with unavailable clear actions dimmed.
- Fixed continuous Library layout work after playback is cleared.
- Checked at narrow phone widths with normal and large text, in light and dark themes.
- Existing lyrics, artists, mixes, radio, crossfade, offline music and Smart features remain available. YouTube account connection is optional.
- Install as an update over your existing app, including 0.28.0-dev, to keep your music and settings. Version code 45 uses the original signing identity.
