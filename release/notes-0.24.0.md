# VEXO Music 0.24.0

- Artwork fills its frame without stretching, with detected symmetric black video borders removed.
- Cleaner Home filters and aligned cover cards, a slimmer mini-player, and an artwork-tinted player.
- Playing a search result starts that song, then continues with related radio.
- Starting radio keeps the current song, playback position and manual queue.
- Fewer duplicate radio/player controls; YouTube account connection remains optional.

MindRadio, PureSong, Smart Experience, crossfade, offline music, accounts and playlists remain available.

Install as an update without uninstalling to keep saved data. This release uses the original app signing certificate and version code 34, updating both public 0.22.0/code31 and 0.24.0-dev/code33. Physical-device audio, Bluetooth and background behavior still require device acceptance testing.
