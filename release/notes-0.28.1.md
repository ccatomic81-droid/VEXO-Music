# VEXO Music 0.28.1

- Update alerts and push release alerts default to ON for new installs and preferences absent on older versions.
- Android notification permission is still required. Granting it connects release alerts automatically, including after returning from Android Settings.
- Denying Android permission keeps the saved alert preference, with a clear permission-needed status.
- Crossfade defaults to 4 seconds. Saved Off choices and custom durations remain available.
- Existing music, playlists, profile, queue, radio and other features are retained.
- Install as an update over your current VEXO app to keep your data. Version code 46 uses the original signing certificate.
