# VEXO Music 0.25.1

- Animated in-app update screen with real download percentage, MB transferred and a separate integrity/signature verification phase.
- Cancel an update download or retry a failed attempt. Android still asks before installation.
- Automatic offline saving restored, with a working Settings switch and the existing 500 MB storage limit. Complete saves survive restart and work without internet.
- TikTok-inspired Trending Music, personalized mood mixes, Daily Mix, New to you and Tune My Mix.
- Continuous mix queues, local listening-interest learning and priority for manually queued songs.

MindRadio, PureSong, Smart Experience, crossfade, playlists, accounts and optional YouTube connection remain.

Install over the existing app to keep your data. Version code 37 updates public 0.24.0 and 0.25.0-dev/0.25.1-dev testers using the original signing certificate. The download animation becomes available after this version is installed and will be used for subsequent in-app updates.

Offline check: enable Settings → Auto-save offline music, wait for a completed song under Library → Offline, then replay it in airplane mode and after reopening the app. Automated cache/transport/UI checks do not replace physical-phone audio, Bluetooth and background acceptance.
