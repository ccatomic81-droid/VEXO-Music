# VEXO Music 0.16.0

- One-time first-visit notification invitation: Enable or Not now. Already-enabled users and recorded refusals are skipped.
- Aurora Home, purple/lime styling, aligned playlists, floating navigation and rounded mini-player artwork.
- Optional Google/email sign-in, explicit online favourites/playlist sync, and optional release alerts in Settings.
- Existing music, preferences, playback, crossfade, search, Smart Experience, MindRadio and FairPlay are preserved.

Install as an update over the existing VEXO app; do not uninstall or clear app data. The source project was recovered after a workspace reset and checked with account, storage, notification, UI and existing playback tests. Native Google account selection and FCM delivery still require physical-device acceptance; no notification/email campaign is sent as part of publication.
