# VEXO Music 0.11.0 development test release

Developer: Kavindu Kavishka.

Cloud MindRadio now interprets requests and refinements using Workers AI, with a small free daily allowance and an explicit consent step. The app keeps a local-radio option when cloud AI is unavailable.

Live FairPlay rooms let a host share an expiring invite, listeners request tracks, and the host advance a fair queue. Host playback state is synchronized to followers; each device streams independently. Rooms support up to eight members and expire after two hours.

The redesigned native interface uses translucent glass, highlights, readable navigation labels and a fifth Smart tab after Settings. Window blur is used only when supported; Android 8+ retains the lightweight glass treatment.

Private memories, history and playlists are preserved. Install as an update over the old VEXO app. This remains a development build: physical-device sync/battery testing is needed, and licensed lyric search, full popularity/audio-feature metadata, and authorized online downloads remain separate dependencies.
