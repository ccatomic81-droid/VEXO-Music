# VEXO Music 0.10.0 development candidate

Developer: Kavindu Kavishka.

Adds private listening-history search with dates, song memories with saved moments, Playlist Time Machine, anti-repeat controls, detailed feedback, discovery journeys, local FairPlay rotation and customizable Home. Extends multilingual search and network recovery while keeping the existing playback, queues, crossfade, profiles, playlists and update system.

MindRadio currently uses descriptive search and local ranking. Cloud AI, multi-device sessions, licensed lyric search, verified popularity/audio-feature metadata and comprehensive transliteration are not connected. New online offline saves require provider authorization. See `docs/SMART-EXPERIENCE.md` for all 12 feature statuses.

This is a review candidate, not a stable update. Install only an APK signed with the existing VEXO certificate over your current app; do not uninstall or use the runner debug APK to replace a stable installation. Device checks and outstanding external integrations remain before a stable release. The stable update feed is not changed by preparing this candidate.

Published for opt-in testing: https://vexo-music-testing.kavindukavishka785.workers.dev/ . The APK uses the original VEXO signing certificate and the same application ID. Download it directly and choose Update; the normal stable update button is not changed. Report device issues using Settings → Report a problem.
